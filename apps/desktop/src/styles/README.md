# QDT UI 스타일 기준

기존 앱의 파스텔 테마와 8px 모서리를 유지한다. 사용자 지정 색상은
`../theme/themeOptions.ts`의 의미별 토큰으로 전달한다.

- 시작 화면은 `entry.css`가 담당한다. Gemini/에이전트의 테두리 없는 두 카드 전체를 눌러 작업 준비로 바로 이동한다. 파일·출력·검수·에이전트·번역 기준은 작업 준비에서 설정하며 방식 재선택 때 기존 입력을 보존한다. 장식 그림은 보조 수단이며 카드 이름·설명과 키보드 초점으로도 선택할 수 있어야 한다.

- 드롭다운은 `components/Select.tsx`와 `controls.css`만 사용한다. 트리거와 펼친 목록 모두 테두리 없이 테마 색상을 쓰며 44px/14px/8px 규격을 공유한다. Enter·방향키·Home/End·문자 검색·Escape·Tab을 지원한다. 선택은 클릭/Enter로 확정하고 Escape/바깥 클릭은 값을 바꾸지 않는다.
- 파일/폴더는 `SegmentedControl`의 단일 표시 배경이 180ms 동안 이동한다. 버튼마다 선택 배경을 중복 적용하지 않으며 동작 줄이기 설정에서는 즉시 전환한다.
- 접기/펼치기 및 키 상태는 로컬 Lucide SVG(`assets/icons`, 라이선스 포함)를 사용한다. 화살표 글자를 쓰지 않는다. 키 저장 상태는 연결 성공을 뜻하지 않는다.
- 제목으로 이동한 프로그램 포커스에는 외곽선을 표시하지 않는다. 조작 가능한 컨트롤의 키보드 포커스 표시는 유지한다.

- 일반 동작 버튼의 단일 기준은 `buttons.css`다. 화면별 CSS는 배치와 너비만 정한다.
- 모든 버튼의 테두리는 없다. 선택 표시를 테두리처럼 보이는 내부 그림자로 대신하지 않는다.
- 주요 동작은 `primary-button`의 기존 테마 그라데이션, 보조 동작은 `secondary-button`의 테마 배경색을 쓴다.
- API 설정, 검수, 용어집에도 같은 클래스를 사용한다. 별도 버튼 스타일을 추가하지 않는다.
- 일반 버튼: 최소 높이 44px, 모서리 8px, 글자 14px/700, 안쪽 간격 10px 16px.
- 선택 카드와 탐색 항목은 내용에 맞는 크기를 사용하되 테마 토큰과 테두리 없는 상태를 유지한다.
- 비활성 버튼은 동작하지 않고 흐리게 표시한다. hover/active 효과도 적용하지 않는다.
- 키보드 `focus-visible` 외곽선은 접근성을 위한 일시적 표시이므로 유지한다.
- 고정 회색·검정 색상을 화면별로 넣지 않는다. 밝은 테마, 어두운 테마, 사용자 지정 색상을 함께 확인한다.
- 세로 강조선과 색상 박스를 결합한 안내 UI는 사용하지 않는다. 정상 안내는 간결한 본문, 실제 오류는 원인과 조치로 표시한다.
- 결과 화면의 제목 20px, 섹션 16px, 본문·파일명·버튼 14px, 보조 설명 13px를 사용한다. 긴 전체 경로는 기본 화면에서 반복하지 않는다.
- 사용자 산출물은 PDF만 표시하고 집계한다. JSON·MD·HTML·PPTX 등 내부 파일을 PDF와 같은 결과 목록에 넣지 않는다.
- 결과·검수·패치노트 요약은 `SummaryCards`를 공유한다. 라벨 13px, 값 24px(문자 상태는 16px), 안쪽 간격 12px 14px로 약 76px 높이를 사용한다. 작은 화면에서는 두 열로 배치한다.
- 패치노트는 제목·날짜·상태만 있는 10건 단위 목록이다. 검색과 페이지 이동을 지원하며 상세는 한 항목씩 펼친다. 각 변경의 검증 근거를 상세에 유지한다.
- API 설정은 기본으로 접힌 탐색 항목이다. `aria-expanded`와 키보드 동작을 제공하고 접어도 미저장 입력을 유지한다. API 사용 여부를 바꾸는 스위치가 아니다.
- 고장모드의 이동 버튼은 해당 설정을 펼치고 관련 컨트롤에 초점을 준다. 이동만으로 설정 저장·키 삭제·연결 검사·번역 재실행을 하지 않는다. 원문 보존·응답 형식 오류는 실행 상세로 안내한다.
- 용어집은 분류 선택을 한 곳에 두고, 검색·용어 추가와 목록을 주 작업으로 배치한다. 현재 분류 카드·중복 분류 필터·장식 배지는 사용하지 않는다. 파일 가져오기/내보내기는 목록 아래의 기본 접힘 영역에 모은다.
- 용어집 입력란은 44px 높이·14px 글자·8px 모서리와 테마 배경을 사용한다. 펼치기 제목은 API 설정과 같은 16px/13px 구조다. 모달은 키보드 초점을 가두고 Escape로 닫으며 닫은 뒤 호출한 버튼으로 돌아간다.

검증: `node --test tests/themeOptions.test.mjs tests/safetyRegression.test.mjs`,
프론트엔드 빌드 후 `python scripts/verify-ui-buttons.py`(저장소 루트).
브라우저 검증은 가상 작업을 사용하며 API 호출이나 실제 검수 결정을 변경하지 않는다.

용어집 검증: `python scripts/verify-glossary-ui.py`.
과거 클래스명·테두리·중복 필터를 고정하던 `glossaryWorkspaceCopy.test.mjs`의 8개 소스 문자열 검사는 새 UI 계약에 따라 위 브라우저 검증으로 대체했다. 분류 선택, 검색, 추가/삭제, 분류 관리, 파일 교환, 오류 복구, 키보드 모달을 실제로 조작해 확인한다.
